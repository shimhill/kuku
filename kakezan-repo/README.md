# かけざん れんしゅう帳

子ども向けの九九(かけざん)練習アプリです。ブラウザだけで動きます。

## できること

- 1〜9の段からランダムに出題
- 練習する段を選べる(「ぜんぶ」「にがてだけ」もあり)
- 5問連続正解でほめる
- 10問連続正解ごとに、犬のモニーがほめてくれる
- まちがえた問題は3問後にもう一度出題し、そのあとも出やすくなる
- 「にがてマップ」で、まちがえた問題が赤く表示される(正解するとうすくなる)
- キーボード入力(数字・Enter・Backspace)にも対応

記録(にがてマップ・最高連続記録)は、使っている端末のブラウザに保存されます。

## ファイル構成

```
index.html               アプリ本体(HTML・CSS・JavaScript)
images/mony1〜6.webp     10問連続正解のときに出るモニーの画像
images/mony-sticker.webp 問題の上に出る小さなモニー
```

## GitHub Pages で公開する方法

1. このフォルダの中身をリポジトリにアップロードする
2. リポジトリの **Settings → Pages** を開く
3. **Source** で「Deploy from a branch」、ブランチは `main`、フォルダは `/ (root)` を選んで保存する
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになる

## カスタマイズのヒント

- モニーの画像を変える:`images/` の画像を同じ名前で差し替える
- 画像の枚数を変える:`index.html` の `MONY_PICS` の一覧を編集する
- モニーが出る間隔を変える:`index.html` の `streak%10` と `10-(streak%10)` の `10` を変える
